# Exact bounded claims and prohibited claims

## Claim suitable for a structured Abstract Results statement

“In a deterministic headless semantic model, 868 selected test instances matched their frozen expected outcomes, including representative effects for all 24 actions, typed canonical-key comparisons and independently scoped multi-rule scenarios. The evaluation covers model behaviour given controlled observations; browser acquisition, rendering and empirical user outcomes were not evaluated.”

## Claim suitable for Discussion

“The verification supports policy-consistent behaviour of the declared semantic model and selected stateful scenarios. It provides representative evidence for action effects, concurrent rule/action handling and deterministic canonical comparison, while preserving earlier failures and retests. It does not establish complete implementation correctness, exhaustive combination coverage or empirical accessibility effectiveness.”

This is an approved claim formulation for later use, not a draft of Section 7.

## Exact claims that remain prohibited by the available evidence

- “The complete implementation has been verified.”
- “All possible combinations of the 24 actions have been tested.”
- “The framework is correct for every context, service or runtime sequence.”
- “Browser-based context acquisition and reflow detection are accurate.”
- “The implementation preserves actual DOM nodes, focus, selection and IME composition.”
- “All task-relevance predicates are derived correctly from natural user behaviour.”
- “The adaptive UI improves comprehension, reduces cognitive load or increases usability.”
- “The framework demonstrates clinical or cognitive-accessibility effectiveness.”
- “The system is production-ready or legally equivalent to an official government transaction.”
- “The framework achieved a universal 100% verification pass rate.”
- “No defects or verification failures occurred.”

The final 868/868 figure is agreement on a selected executable inventory. Earlier failures are retained, oracle-tag totals overlap, and browser/IME categories are outside the declared evaluated domain.
